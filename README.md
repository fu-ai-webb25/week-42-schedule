# Schema, vecka 42
###### Utveckling av AI-drivna applikationer, vecka 2 av 4

## Introduktion

I denna modul går vi från en enkel chatbot till en mer avancerad AI-driven applikation. Vi fördjupar oss i hur prompts och systeminstruktioner kan användas för att styra språkmodellens beteende och hur information kan skickas genom flera steg i ett arbetsflöde.

Vi kommer även att arbeta med verktyg och function calling, vilket gör det möjligt för språkmodellen att använda funktioner och externa datakällor när den behöver information som den inte själv har tillgång till. På så sätt kan vi bygga applikationer där modellen inte bara genererar text utan också kan fatta beslut om vilka verktyg som behöver användas för att lösa en uppgift.

## Mål för veckan:

1. Förstå hur olika typer av prompts påverkar språkmodellens svar
2. Kunna använda systemmeddelanden och prompt templates för att styra modellens beteende
3. Kunna bygga flerstegsflöden med LangChain.js
4. Förstå skillnaden mellan ett förutbestämt arbetsflöde och ett AI-styrt arbetsflöde
5. Förstå principen bakom tool calling / function calling
6. Kunna skapa och koppla verktyg till en språkmodell
7. Kunna bygga en chatbot som kan använda externa funktioner eller API för att lösa uppgifter
